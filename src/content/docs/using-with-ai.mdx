---
title: Using this with AI
description: How to get on-brand output from an AI assistant.
---

## Agents working in this repo (or through a file/GitHub MCP)

Point the agent at the repo. It should read `llms.txt` first (`AGENTS.md` and `CLAUDE.md` tell it to). From there it finds each brand's `brief.md`, which has everything in one file: setup, voice, rules, tokens, assets and component code with overrides already applied.

Example prompts:

> Using the Disciple.Tools brand from the design system, build a settings page with a form and a save button.

> Check this page against the Prayer.Global brand and list anything that breaks the rules.

> Add a "badge" component to the shared system, then run the check.

## Chat assistants (no repo access)

Open the brand's **Brief for AI** page, click **Copy brief**, and paste it at the start of the conversation.

## Raw files

The site serves the same paths as the repo, under https://gospelambition.github.io/design-guide/:

- `/llms.txt`: the index
- `/brands/<id>/brief.md`: one brand, resolved
- `/brands/<id>/tokens.css`: drop-in CSS variables
- `/brands/<id>/...` and `/system/...`: every source file
