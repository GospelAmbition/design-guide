## Voice

Calm, precise, reassuring. Neutral tone. Avoid exclamation marks.

## Principles

- **Clarity over decoration.** Every element earns its place.
- **Dense but ordered.** Fit a lot on screen, aligned to the spacing scale.
- **Works in the dark.** Every screen must work in both light and dark mode.

## Do

- Use primary sparingly; most UI should be neutral.
- Keep layouts dense but aligned to the spacing scale.
- Use a single typeface (IBM Plex Sans) in different weights.
- Use small, consistent corner radii.

## Don't

- Don't use decorative or script fonts.
- Don't use more than one accent colour on a screen.
- Don't use large rounded corners (over 8px).
- Don't use exclamation marks in UI copy.
